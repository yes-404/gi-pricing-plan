# W37-11 residue record

The governed per-(file, class) residue ceiling `scripts/_docverify.py`'s
`load_w37_11_record` reads (`W37_11_RECORD_PATH`). Population is the deputy's, filed one
entry at a time as W37-6's ruled DISCLOSE-with-residue rows are worked — never the code's,
and never invented ahead of the ruling that names it.

Each row: which file, which ruled row/check (`cls`) its count belongs to, the count itself,
a one-line reason it resisted the general migration mechanism, and its owner. A `cls` with
no row here is ungoverned — `check_residue_ceiling` compares nothing against it — so adding
this file's first row for a `cls` is what puts that ruled row under the ceiling; until then
its residue is measured but never gated.
