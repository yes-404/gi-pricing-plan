# F94 — the plan's ruling-heading census uses a looser predicate than the shipped splitter, and the two candidate predicates diverge at `32fc63c`

**Filed 2026-09-02 at `32fc63c`**, on the lead's direction, from condition 1's re-derivation. Id
allocated by the lead and verified free before use. **Filing was deliberately deferred** until
after the re-ask's figures were measured, because adding a file to `docs/` moves the population
those figures count.

## Two defects, one predicate

**(1) The disclosure figure and the population the code will act on are not the same set.** The
plan's census reports **96 over 40**; `doc-id.py`'s shipped `_RULING_HEADING_RE` finds **92 over
37**. **A four-document gap between what the plan expects W37-6 to touch and what W37-6's own code
will find**, and it survives whichever predicate a reader prefers.

**(2) The predicate is not uniquely determined.** Two candidates both give **95/39** at `64f63ee`
and **diverge at `32fc63c`** — 96/40 against 97/41. Agreement at one pin was never evidence that
they measured the same thing; it is
[`NT-0004`](../../notes/0004-a-reference-that-resolves-only-for-the-writer.md)'s predicate clause,
which the maintainer added on 2026-09-02 discharging F85 for exactly this shape: **two counts at
the same tree over the same corpus differing only by pattern.**

## Why it is a finding rather than a caveat

The precedent is F87's, in its own words: the fact *"lived only in a passing test … invisible to
whoever plans W37-6, who is the person who needs it."* Here it would live only in a **decision
document that freezes at filing**. **A W37-6 planner sizing the run from the disclosure would plan
for 96 rulings and the code would touch 92.**

## Not blocking, stated before why it matters

**No NT-0019 §7 acceptance item depends on either figure.** This is not grounds to withhold a
go-ahead, and it was not the ground on which the 2026-09-02 go-ahead was withheld
(`docs/plans/2026-09-02-w37-6-second-withholding-and-standing-rules.md` §1).

**It is also not F90.** F90 is about a *detector's depth-blindness* reddening documents that exist
after the run; this is about *which documents the run creates at all*. They meet only in that both
concern ruling headings.

## Owner and decay event

**No individual owner.** Per Ruling 49 Text B a row without one names the event that next confirms
or assigns it: **W37-6's closure record**, which the 2026-09-02 stopping rule makes the destination
for everything found after the re-ask's tree; failing that, the next `CLAUDE.md` §14 plan review.

**The resolution is not obvious and this finding recommends none of the three:** adopt the shipped
splitter's predicate as the disclosure figure; keep both and state which each answers; or change
the splitter, which is a code change with its own proof and is not a documentation fix.

## Falsifiable

Wrong, and reopens, if **one** predicate can be shown to answer both questions — which population
the disclosure describes and which population the migration acts on — at two trees, not one.

*Violation: a document stating a ruling-heading count without naming the predicate that produced
it, at a tree where the two candidates disagree.*
